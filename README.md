# دليل خدماتكوم - نظام طلب الخدمات المتكامل

## 📋 نظرة عامة

## ⚙️ إعداد Google Sheets

### الخطوة 1: إنشاء Google Sheet جديد
1. اذهب إلى [Google Sheets](https://sheets.google.com)
2. أنشئ جدول جديد سمّه "Khidmatcom"
3. احذف الورقة الافتراضية

### الخطوة 2: إنشاء Apps Script
1. اضغط على **Tools** → **Script editor**
2. احذف الكود الافتراضي
3. انسخ محتوى ملف `google-apps-script.gs`
4. احفظ الملف

### الخطوة 3: نشر Apps Script
1. اضغط على **Deploy** → **New deployment**
2. اختر **Web app**
3. اختر "Execute as: Your Account"
4. اختر "Who has access: Anyone"
5. اضغط **Deploy**
6. انسخ رابط النشر (Deployment URL)

### الخطوة 4: تحديث رابط الاتصال
في ملف `khidmatcom.config.js`، حدّث:
```javascript
GOOGLE_SCRIPT_URL: 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec',
```

استبدل `YOUR_DEPLOYMENT_ID` برابط النشر الكامل من **Deploy → Web app**.

### الخطوة 5: الأوراق المطلوبة
يتم إنشاء الأوراق تلقائياً:
- **الطلبات:** تخزين جميع طلبات العملاء
- **الفنيون:** قائمة الفنيين المسجلين
- **التحليلات:** إحصائيات النظام

## 🛠️ استكشاف الأخطاء

### المشكلة: النموذج لا يرسل البيانات
**الحل:**
1. تحقق من رابط Apps Script
2. تأكد من النشر الصحيح
3. افتح console (F12) وابحث عن الأخطاء

### المشكلة: البيانات لا تظهر في Sheets
**الحل:**
1. تحقق من صلاحيات الكتابة
2. تأكد من اسم الأوراق
3. حاول النشر من جديد

### المشكلة: لا تظهر الصور
**الحل:**
استبدل روابط الصور بروابط صحيحة:
```html
style="background-image: url('رابط الصورة')"
```
